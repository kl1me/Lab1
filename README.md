# Поморцев Аким КМБ-1 Лабораторная №0

# Задание 1

## Задача 1

### Текст задачи

Создать список из двух чередующихся символов (символы вводятся с клавиатуры)

### Алгоритм решения

Пользователь вводит символ, осуществляем проверку на единственность введенного символа, если символ не один, запрашиваем снова. То же самое и со вторым символом. Создаем изначальный список, состоящий из этих двух символов и передаем в функцию повторения. Пользователь вводит количество повторений, проверяем число на натуральность, если ненатуральное - запрашиваем снова. Если число введено корректно - передаем в функцию повторения списков. На рекурсивном спуске присоединяем к изначально пустому списку оригинальный, постепенно уменьшая количество повторений на 1, пока не дойдем до 0. Происходит возврат списка и его вывод в консоль. Программа завершила работу.

# Задание 2

## Задача 1

### Текст задачи

Найти сумму цифр натурального числа.

### Алгоритм решения

Пользователь вводит число, проверяем его на натуральность, если число ненатуральное - повторяем ввод. Если натуральное - передаем в рекурсивную функцию поиска суммы цифр. На рекурсивном спуске суммируем остаток от деления на 10, и передаем число, разделенное на 10. Выводим результат в консоль. Программа завершила работу.
